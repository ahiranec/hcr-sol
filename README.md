# HCR Sol

Plataforma corporativa interna para gestión de proyectos.

## Stack
- Vite + React + TypeScript
- Tailwind CSS v4
- Supabase (autenticación y base de datos)

## Scripts
```bash
pnpm install    # Instalar dependencias
pnpm dev        # Servidor de desarrollo
pnpm build      # Build de producción
pnpm typecheck  # Verificar tipos TypeScript
```

## Archivos del sistema (Figma Make)
- `__figma__entrypoint__.ts` — no modificar
- `guidelines/Guidelines.md` — archivo protegido por Figma Make; se deja tal cual
